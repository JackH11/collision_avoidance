## Note

Greedy-to-goal is a strong scripted baseline (~45% on baseline @ N=20), close to
Phase 2 CNN ~48% @ N=50. Learned policies must clear the gate **and** preferably
beat greedy on collision / near-miss / hard — Phase 4+ can tighten the gate or
add a greedy-relative check.
